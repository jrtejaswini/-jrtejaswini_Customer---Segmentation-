📌 Project Overview


This project applies Unsupervised Machine Learning to discover hidden customer groups in unlabeled retail data. Raw behavioral signals are transformed into mathematically isolated, strategically actionable market segments using a full Scale → Compress → Cluster → Translate pipeline.


 Requirements


numpy
pandas
matplotlib
scikit-learn


🧠 Key Skills Demonstrated


•Dimensionality reduction (PCA)
•Distance-based clustering (K-Means)
•Optimal K selection (Elbow Method + Silhouette Score)
•Feature standardization
•Business intelligence translation
•Data visualization (2D + 3D scatter plots)
